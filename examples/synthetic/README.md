# Synthetic UNSW demo

`unsw-demo-mixed.csv` is wholly generated, not a real log or benchmark row. Its four Attack and eight Normal labels are invented annotations. Its two feature patterns were selected to exercise both S2 predictions (four ATTACK, eight NORMAL with the verified artifact). It is not suitable for measuring accuracy, F1, model performance, or real-world threat prevalence. It matches the built-in UNSW demo and can be uploaded by choosing UNSW-NB15.
